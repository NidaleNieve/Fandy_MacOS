# Install Fandy

## Download and open

1. [Download Fandy](https://github.com/NidaleNieve/Fandy_MacOS/releases/latest/download/Fandy-0.2.0-arm64.dmg).
2. Open the DMG and drag **Fandy** onto **Applications**.
3. Open Fandy. Click the fan icon in your menu bar to choose a profile.

Requires an Apple Silicon MacBook Pro and macOS 15 or later.

## Allow fan control

In Fandy’s setup window, click **Open System Settings…**. Go to:

**General → Login Items & Extensions → Background App Activity → Fandy**

Enable Fandy. If profiles remain gray, choose **Allow Fan Control…** from its menu. Use one fan-control utility at a time.

## If macOS blocks opening

This release is signed but **not notarized**, so macOS may block it.

Follow [Apple’s opening instructions](https://support.apple.com/en-us/102445): **System Settings → Privacy & Security → Open Anyway**, when offered. Do not disable macOS security protections. If macOS reports damage or malicious software, stop and [report the message](https://github.com/NidaleNieve/Fandy_MacOS/issues).

## Updating

Choose System and quit Fandy. Replace the copy in Applications with the new release, then reopen it.
