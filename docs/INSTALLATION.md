# Install Fandy

Requires an Apple Silicon MacBook Pro and macOS 15 or later. See [Compatibility](COMPATIBILITY.md).

1. [Download the DMG](https://github.com/NidaleNieve/Fandy_MacOS/releases/latest/download/Fandy-0.4.0-arm64.dmg) and drag **Fandy** into **Applications**.
2. Open `/Applications/Fandy.app` and follow setup.
3. Enable **Fandy** in **System Settings → General → Login Items & Extensions → Background App Activity**.
4. Click the menu-bar fan icon and choose a profile.

Keep the app at `/Applications/Fandy.app` so its helper can register. Run one fan-control utility at a time.

## Updates

Automatic checks run daily by default. Settings lets you change the frequency, disable automatic checks, check manually or install a downloaded update. Background updates normally install when you quit.

For a manual update, choose System, quit, replace the app in Applications, and reopen it. Profiles and preferences are preserved.

## Troubleshooting

Open the copy in Applications and confirm Background App Activity is enabled. Use **Allow Fan Control…** or setup's retry action. For an invalid or damaged installation, reinstall a signed download. Do not delete a helper while it owns the fans.

[Report an issue](https://github.com/NidaleNieve/Fandy_MacOS/issues) with your Mac model, macOS version, Fandy version and displayed error. Check attachments for personal information before posting.
